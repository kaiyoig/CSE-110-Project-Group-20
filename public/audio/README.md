# Background music

Place the original **Spy.mp3** download here as `spy-loop.mp3`.

- Track: Spy Loop
- Artist: wipics
- Source: https://opengameart.org/content/spy-loop
- License: CC0 / public domain, as listed by the artist.

The game loads the local file relative to Vite's base URL, loops it after a user gesture, and provides independent music and sound-effects controls. No remote audio service is needed. Until the MP3 is added, the game runs without background music.
